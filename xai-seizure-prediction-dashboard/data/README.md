# CHB-MIT Scalp EEG Dataset Directory

This directory contains EEG recordings from the **CHB-MIT Scalp EEG Database**, collected at Boston Children's Hospital.

## Format & Montage
- Recordings are formatted in European Data Format (`.edf`).
- Standard 10-20 international system bipolar electrode montage (18 standard channels: `FP1-F7`, `F7-T7`, `T7-P7`, `P7-O1`, `FP1-F3`, `F3-C3`, `C3-P3`, `P3-O1`, `FP2-F4`, `F4-C4`, `C4-P4`, `P4-O2`, `FP2-F8`, `F8-T8`, `T8-P8`, `P8-O2`, `FZ-CZ`, `CZ-PZ`).
- Sampling frequency: 256 Hz.
- Clinical annotations (`.seizures`) indicate expert-annotated seizure onset and offset timestamps in seconds.
